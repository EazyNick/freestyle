# Freestyle Image Clicker

Python automation script that finds images from the `img` folder on the current screen and clicks them in order.

## Setup

Dependencies are installed in the local virtual environment:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Run

```powershell
.\.venv\Scripts\python.exe main.py
```

Edit `env.env` to choose the target folder, delays, confidence, and loop behavior.
